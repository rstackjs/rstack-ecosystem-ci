# Ecosystem CI website

The website uses TanStack Start in SPA mode, built with Rsbuild through
`rstack.config.ts` and the `rs` commands.

- `pnpm dev`: fetch history and start the development server.
- `pnpm dev:mock`: start with mock data.
- `pnpm dev:cached`: start with previously fetched history.
- `pnpm build`: fetch history and build the static site.
- `pnpm preview`: preview the production build.

Run these commands from `website/`, or run `pnpm build:website` from the repository
root. Route types are generated by `rs dev` and `rs build`.

## Cloudflare Pages

Keep the existing build command (`pnpm build:website` from the repository root)
and change the Cloudflare Pages build output directory from `website/dist` to
`website/dist/client`. The build generates the SPA shell as
`dist/client/index.html`, so Cloudflare Pages can serve the site with its default
SPA fallback. No Worker or Pages Function is required.

TanStack Start's server bundle is used only to prerender the SPA shell and is
written to `dist/server`. Publish only `dist/client`, not the entire `dist`
directory. History remains loaded at build time, and the existing scheduled
Pages deploy hook is unchanged.
